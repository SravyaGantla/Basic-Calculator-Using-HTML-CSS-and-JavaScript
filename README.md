# Basic-Calculator-Using-HTML-CSS-and-JavaScript
The Basic Calculator is a web-based application developed using HTML, CSS, and JavaScript that performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division. The project provides a simple and user-friendly interface where users can enter numbers and perform calculations instantly. 
The calculator consists of a display screen to show input values and results, along with buttons for digits, operators, clear, and delete functions. JavaScript is used to handle user interactions, process calculations, and display results dynamically. The application also includes error handling to prevent invalid calculations and keyboard support for enhanced usability.
CSS is used to create an attractive and responsive design, ensuring the calculator works smoothly across different screen sizes and devices. This project demonstrates the use of front-end web technologies, event handling, DOM manipulation, and basic programming logic.
Objectives
To develop a calculator capable of performing basic arithmetic operations.
To create an interactive and user-friendly interface.
To implement real-time calculation and result display.
To understand JavaScript event handling and DOM manipulation.
To enhance user experience through responsive design and keyboard support.
Features
Addition (+)
Subtraction (−)
Multiplication (×)
Division (÷)
Percentage (%)
Clear Screen Function
Delete Last Character Function
Real-Time Display Updates
Keyboard Input Support
Error Handling for Invalid Expressions
Responsive and Attractive User Interface
Technologies Used
HTML – Structure of the calculator.
CSS – Styling and layout design.
JavaScript – Calculator functionality and user interaction.
